# Classy Dishes implementation outcomes

- Build a responsive home page with a restaurant logo, navigation menu, welcome message, large food photograph, Order Now and Explore Menu buttons, featured dishes, and special offers.
- Build an Our Menu section organized into Kenyan dishes (ugali, nyama choma, pilau, chapati), international dishes (pasta, burgers, pizza, grilled chicken), starters, desserts, and drinks, with photographs, descriptions, and prices in KSh.
- Add client-side ordering with Add to Cart controls, a quantity-aware shopping cart, automatic total calculation, and customer name, phone number, and delivery address fields with checkout or WhatsApp submission.
- Add a table reservation form for customer name, phone number, date, time, guests, and special requests, with an on-page confirmation message.
- Add About Us storytelling and a beachside gallery showing food, restaurant setting, and dining experience.
- Add Contact Us details including location, opening hours, phone number, WhatsApp link, social pages, and a map link.
- Keep the implementation as a responsive single-page site using only HTML, CSS, and vanilla JavaScript, with no server or database.
